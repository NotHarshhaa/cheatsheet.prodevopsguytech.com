## How to Use This Hub

- **Search Anything:** Press <kbd>Ctrl</kbd> + <kbd>K</kbd> (or <kbd>⌘</kbd> + <kbd>K</kbd> on macOS) to instantly search all 35 cheatsheets by command, keyword, or tool name.
- **Copy Terminal Commands:** Every code block has an instant one-click copy button.
- **Raw Markdown & AI Exports:** Every cheatsheet is available as raw Markdown at `/docs/<category>/<tool>.md` and compiled into `/llms.txt` and `/llms-full.txt` for agentic workflows.
- **Edit & Contribute:** Found an updated CLI flag or new recipe? Click **"Edit on GitHub"** at the bottom of any page to submit a pull request!
